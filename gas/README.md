# 通知を送る（Google Apps Script）

`notify.gs` は、Googleが無料で動かしてくれるプログラム（Google Apps Script、以下GAS）です。🐱のGoogleアカウントで動かしています。5分ごとに動き、通知の中継（`worker/`）を通して、カレンダーのアプリに次の通知を送ります。通知をタップすると、ホーム画面のアプリが開きます。

- **毎朝6時**（6:00〜6:05ごろ）：今日の全員の予定。予定がない日は「今日の予定はありません」。自分のタスクは、期限の5日前・2日前・1日前・当日に一緒に送る（完了したものは送らない）
- **相手が予定を追加したとき**（5分以内）：追加した人でないほうに送る
  - アプリ以外（メールなど）からGoogleカレンダーに入った予定も送る
  - 変更では送らない
- **相手がアプリで予定を削除したとき**（5分以内）：削除した人でないほうに送る
  - アプリが削除した人のカレンダーに残す「削除の記録」で知る。Googleカレンダーのアプリで直接消した予定は送れない
- タスクは、対象の人のうち、入れた（削除した）人でない人にだけ送る

カレンダーのアプリ本体（GitHub Pages）とは別に動きます。

## 最初の設定（パソコンで、🐱のGoogleアカウント）

先に `worker/README.md` の 1〜4（通知の中継）を済ませておく。

1. https://script.google.com/home を開き、カレンダーのアプリでログインしているGoogleアカウントで「新しいプロジェクト」を作る
2. 左上の「無題のプロジェクト」を押して、名前を「our_calendar 通知」にする
3. 「コード.gs」の中身をすべて消し、`notify.gs` の中身をすべて貼り付けて保存（Ctrl＋S）
4. 左の「サービス」の「＋」→「Google Calendar API」を選んで「追加」（IDは `Calendar` のまま）
5. 左の ⚙「プロジェクトの設定」の下にある「スクリプト プロパティ」で、次の2つを追加して保存する

   | プロパティ | 値 |
   |---|---|
   | `PUSH_URL` | 通知の中継の URL（`https://oc-push.chibikurocat4.workers.dev`） |
   | `PUSH_SECRET` | 通知の中継の合言葉（Cloudflare の `SEND_SECRET` と同じ） |

6. 2人のiPhoneで、カレンダーのアプリの ⚙ →「このデバイスで通知を受け取る」を押しておく
7. エディタに戻り、上の関数の選択で `setup` を選んで「実行」
   - 「承認が必要です」→ アカウントを選ぶ →「このアプリは Google で確認されていません」と出たら「詳細」→「our_calendar 通知（安全ではないページ）に移動」→「許可」。自分で作ったプログラムなので、この表示が出るのはふつう
8. 2人のiPhoneに「通知の設定ができました」が届けば完了
   - 下の「実行ログ」に、見つかったカレンダーが出る。彼女のカレンダーに 🐟 が付いているか確かめる（🐱のアカウントから見えないカレンダーの予定は、通知に入らない）
9. 朝の通知を今すぐ試すときは、`testDaily` を選んで「実行」

スクリプト プロパティの `notified` と `sync:…` は、プログラムが使う記録なので消さない。

## プログラムを更新するとき
- 「コード.gs」の中身を新しい `notify.gs` に貼り替えて保存するだけでよい（`setup` の実行は不要）
- 朝の通知の時刻は `DAILY_HOUR`、タスクを知らせる日は `TASK_REMIND_DAYS` で変える

## 止めるとき
GAS の左の ⏰「トリガー」で `tick` のトリガーを削除する。

## しくみのメモ
- 予定の追加・削除は、Google Calendar API の `syncToken`（前回からの差分）で調べる。作られてから1時間以内の予定・削除の記録だけを新しいものとみなし、送ったもののIDを2日間覚えて二重に送らない
- アプリで「書き換え」たときにできる予定（`ocSource` つき）、非表示の印、変換済みの印、繰り返しの予定の1回分の変更は「追加」として扱わない
- 誰が追加したかは、予定が入ったカレンダーの持ち主で決める（アプリは、ログイン中の人のカレンダーに保存するため）。誰が削除したかは、削除の記録の `ocDelBy`
- 無料の範囲：GASのトリガーの実行時間は1日90分まで。5分ごと（1日288回）で、1回数秒なので収まる
- 最初は通知アプリ ntfy に送っていたが、タップするとSafariで開くことと、GASの送信元が共有のため ntfy の1日の上限にすぐ達することから、やめた（2026-10-11）
