# 通知（Google Apps Script ＋ ntfy）

`notify.gs` は、Googleが無料で動かしてくれるプログラム（Google Apps Script、以下GAS）です。5分ごとに動き、スマホの通知アプリ ntfy に次の通知を送ります。

- **毎朝6時**（6:00〜6:05ごろ）：今日の全員の予定。予定がない日は「今日の予定はありません」。自分のタスクは、期限の5日前・2日前・1日前・当日に一緒に送る（完了したものは送らない）
- **相手が予定を追加したとき**（5分以内）：もう1人に送る。タスクは、対象の人のうち入れた人でない人にだけ送る
  - アプリ以外（メールなど）からGoogleカレンダーに入った予定も送る
  - 変更・削除では送らない

カレンダーのアプリ本体（GitHub Pages）とは別に動きます。通知をタップすると、カレンダーのアプリが開きます。

## 最初の設定

### 1. スマホに ntfy を入れる（2人とも）
1. App Store で「ntfy」を入れて開き、通知を許可する
2. 右上の「＋」を押し、トピック名に**自分の受け取り先**（Claudeから受け取った `oc-cat-…` または `oc-fish-…`）を入れる。サーバーは `ntfy.sh` のまま「Subscribe」
   - 受け取り先の名前を知っている人は誰でも通知を読めるので、他の人に教えない。GitHub にも書かない

### 2. GAS を作る（パソコンで、🐱のGoogleアカウント）
1. https://script.google.com を開き、カレンダーのアプリでログインしているGoogleアカウントで「新しいプロジェクト」を作る
2. 左上の「無題のプロジェクト」を押して、名前を「our_calendar 通知」にする
3. 「コード.gs」の中身をすべて消し、`notify.gs` の中身をすべて貼り付けて保存（Ctrl＋S）
4. 左の「サービス」の「＋」→「Google Calendar API」を選んで「追加」（IDは `Calendar` のまま）
5. 左の ⚙「プロジェクトの設定」の下にある「スクリプト プロパティ」で、次の2つを追加して保存する

   | プロパティ | 値 |
   |---|---|
   | `TOPIC_cat` | 🐱の受け取り先（`oc-cat-…`） |
   | `TOPIC_fish` | 🐟の受け取り先（`oc-fish-…`） |

### 3. 動かす
1. 左の「エディタ」に戻り、上の関数の選択で `setup` を選んで「実行」
2. 「承認が必要です」→ アカウントを選ぶ →「このアプリは Google で確認されていません」と出たら「詳細」→「our_calendar 通知（安全ではないページ）に移動」→「許可」
   - 自分で作ったプログラムなので、この表示が出るのはふつうです
3. 2人のスマホに「通知の設定ができました」が届けば完了
4. 下の「実行ログ」に、見つかったカレンダーが出る。彼女のカレンダーに 🐟 が付いているか確かめる（🐱のアカウントから見えないカレンダーの予定は、通知に入らない）
5. 朝の通知を今すぐ試すときは、`testDaily` を選んで「実行」

## プログラムを更新するとき
- 「コード.gs」の中身を新しい `notify.gs` に貼り替えて保存するだけでよい（受け取り先はスクリプト プロパティにあるので、入れ直さなくてよい）
- 朝の通知の時刻は `DAILY_HOUR`、タスクを知らせる日は `TASK_REMIND_DAYS` で変える

## 止めるとき
GAS の左の ⏰「トリガー」で `tick` のトリガーを削除する。

## しくみのメモ
- 予定の追加は、Google Calendar API の `syncToken`（前回からの差分）で調べる。作られてから1時間以内の予定だけを「追加」とみなし、送った予定のIDを2日間覚えて二重に送らない
- アプリで「書き換え」たときにできる予定（`ocSource` つき）、非表示の印、変換済みの印、繰り返しの予定の1回分の変更は「追加」として扱わない
- 誰が入れたかは、予定が入ったカレンダーの持ち主で決める（アプリは、ログイン中の人のカレンダーに保存するため）
- 無料の範囲：GASのトリガーの実行時間は1日90分まで。5分ごと（1日288回）で、1回数秒なので収まる
