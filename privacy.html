プライバシーポリシー

Our Calendar（以下「本アプリ」）は、開発者とその家族など、ごく限られた利用者が個人的に使うためのカレンダーアプリです。

取得する情報

本アプリは、利用者がGoogleアカウントでログインして許可した範囲で、Googleカレンダーの次の情報にアクセスします。

  • 利用者が閲覧できるカレンダーの一覧（名前と権限）
  • それらのカレンダーの予定（表示、追加、編集、削除のため）

情報の保存と送信

  • 予定は、利用者のGoogleカレンダーに保存します。予定を保存するための独自のサーバーやデータベースはありません。
  • オフラインでも表示できるよう、予定の一部とログイン情報（一時的なアクセストークン）を、利用者の端末のブラウザ内に保存します。ログアウトすると削除されます。
  • 取得した情報を、第三者に提供・販売することはありません。広告や分析の目的にも使いません。

通知

設定画面で「このデバイスで通知を受け取る」を選んだ場合だけ、予定の通知のために次の仕組みを使います。

  • 通知の中継（Cloudflare Workers で動かしている、本アプリ用のプログラム）に、その端末の通知の受け取り先（ブラウザが発行する宛先と暗号鍵）を保存します。誰の端末かを確かめるため、登録のときにアクセストークンを送りますが、確認に使うだけで保存はしません。
  • 通知の内容（予定のタイトルや日時）は、開発者のGoogleアカウントで動かしているプログラム（Google Apps Script）がGoogleカレンダーから作り、中継を通して端末に届けます。中継は内容を暗号化して送るだけで、保存しません。
  • 受け取りをやめると、中継から受け取り先を削除します。

Google API サービスのユーザーデータに関するポリシー

本アプリによるGoogle APIから受け取った情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

アクセスの取り消し

本アプリへのアクセス許可は、Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
