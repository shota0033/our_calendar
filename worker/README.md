# 通知の中継（Cloudflare Workers）

`push.js` は、カレンダーのアプリ（ホーム画面のアプリ）に通知を届ける中継です。Cloudflare Workers（無料）で動かします。

- アプリの設定画面で「このデバイスで通知を受け取る」を押すと、そのiPhoneの受け取り先がここに登録されます
  - 誰のiPhoneかは、アプリのGoogleログインで確かめます（2人以外のアカウントは登録できません）
- GAS（`gas/notify.gs`）が「この人にこの通知を送って」と頼むと、その人の受け取り先すべてに Web Push で届けます
- 通知をタップすると、ホーム画面のカレンダーのアプリが開きます（`sw.js` の `notificationclick`）

## 最初の設定（パソコンで）

### 1. Worker を作る
1. https://dash.cloudflare.com/sign-up で無料のアカウントを作る（メールアドレスとパスワードだけ。カードは不要）
2. 左のメニューの「Workers & Pages」（「コンピューティング（Workers）」の中）を開き、「作成」→ Worker を作成（「Hello World」から始める）
3. 名前を `oc-push` にして「デプロイ」
4. 「コードを編集」を押し、`worker.js` の中身をすべて消して `push.js` の中身を貼り付け、「デプロイ」

### 2. 保存場所（KV）をつなぐ
1. 左のメニューの「ストレージとデータベース」→「KV」→「作成」で、名前 `oc-push-subs` の保存場所を作る
2. Worker `oc-push` の「設定」→「バインディング」→「追加」→「KV 名前空間」
3. 変数名を `SUBS`、KV 名前空間を `oc-push-subs` にして「デプロイ」（保存）

### 3. 合言葉（シークレット）を入れる
1. Worker `oc-push` の「設定」→「変数とシークレット」→「追加」
2. タイプを「シークレット」、変数名を `SEND_SECRET`、値を Claude から受け取った合言葉にして「デプロイ」
   - 合言葉を知っている人は、2人に通知を送れてしまうので、他の人に教えない。GitHub にも書かない

### 4. 確かめる
1. Worker の URL（`https://oc-push.○○○.workers.dev`）の最後に `/vapid` を付けてブラウザで開く
2. `{"publicKey":"…"}` と出ればOK。この URL（`/vapid` を除いたもの）を Claude に伝える
   - Claude がアプリの `config.js` の `pushUrl` に入れて公開する

### 5. GAS から送るようにする
1. GAS の「コード.gs」を新しい `gas/notify.gs` に貼り替えて保存
2. ⚙「プロジェクトの設定」→「スクリプト プロパティ」に、次の2つを追加

   | プロパティ | 値 |
   |---|---|
   | `PUSH_URL` | Worker の URL（`https://oc-push.○○○.workers.dev`） |
   | `PUSH_SECRET` | 3. の合言葉 |

### 6. iPhone で受け取りを始める（2人とも）
1. ホーム画面のカレンダーのアプリを開き、⚙ →「このデバイスで通知を受け取る」→ 通知を「許可」
2. GAS で `setup` を実行すると、「通知の設定ができました」がアプリの通知として届く

### 7. ntfy をやめる
アプリの通知が届くことを確かめたら、GAS のスクリプト プロパティの `TOPIC_cat` と `TOPIC_fish` を消す（ntfy アプリも消してよい）。

## 無料の範囲
- Workers：1日10万回まで。KV：読み込み1日10万回・書き込み1日1,000回まで。2人の通知なら十分に収まる

## しくみのメモ
- 通知の署名用の鍵（VAPID）は、最初に `/vapid` を開いたときに作って KV に `vapid` として保存する。消すと、登録済みの受け取り先が使えなくなる（アプリで受け取りを登録し直す）
- 受け取り先は KV に `sub:<人>:<受け取り先のハッシュ>` で保存する。届かなくなった受け取り先（404・410）は、送るときに消す
- アプリは、受け取り中なら1日に1回、受け取り先を登録し直す（`notify.js` の `resendIfNeeded`）
